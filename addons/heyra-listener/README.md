# Heyra Listener

Home Assistant Add-on: acoustic event detection (YAMNet + openWakeWord) for
the [Heyra](https://github.com/AxeForging/heyra) ATOM Echo mesh, by
[AxeForging](https://github.com/AxeForging).

See [`DOCS.md`](./DOCS.md) for configuration, or the main
[Heyra README](../../README.md) for the full project.
