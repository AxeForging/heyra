Heyra

Hear what matters in your home.

Dumb edge, smart server. Cheap ESP32 units stream raw audio to a server that classifies it and tells Home Assistant — baby crying, smoke alarm, glass breaking, someone at the door, and more. The smoke alarm detector runs on-device too, so it survives a server or network outage.

Get started
Features
Nine ears, one brain
  • Baby cry — classified server-side via YAMNet
  • Smoke alarm — on-device AND server-side, survives an outage
  • Glass break — with a "nobody home" condition example
  • Dog bark / Doorbell
  • Shout / Scream — split into distinct alerts
  • "Help" / "Socorro" wake words — pipeline ready, models pending
  • MQTT Discovery — entities appear in HA automatically
  • Privacy-first — no audio persisted outside opt-in debug mode
  • Any fleet size — one unit or twenty
Guide
How it fits together

1. Firmware

ESPHome on an ATOM Echo streams raw PCM over UDP and runs a Goertzel/pattern detector for smoke alarms entirely on-device.

2. Server

A small Python service classifies the stream with YAMNet + openWakeWord and publishes events over MQTT.

3. Home Assistant

MQTT Discovery creates the entities; automations and a dashboard ship ready to import.
Use cases
Why people run Heyra
  • Baby monitoring — get notified the moment crying starts, anywhere in the house.
  • Accessibility / elderly care — distress-keyword detection for someone who can't reach a button.
  • Home security backup — glass-break and smoke detection that don't depend on a subscription.
  • General awareness — doorbell and dog-bark alerts even when you're not in the room.

Install
Add it to Home Assistant
  1. Settings → Add-ons → Add-on Store → ⋮ → Repositories
  2. Add https://github.com/AxeForging/heyra
  3. Install Heyra Listener (and Heyra Flasher if you're flashing new units)
